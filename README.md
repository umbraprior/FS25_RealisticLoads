# Realistic Loads
This script mod enhances the game by incentivizing the player to utilize the already in-game mechanics for transporting goods. Loose grains and others, like wheat or woodchips, will blow out of trailers when moving too quickly. Heavier goods are better at staying in the trailer than lighter ones. Make sure you tarp it!
